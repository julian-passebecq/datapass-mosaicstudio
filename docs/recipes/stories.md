# Authored stories

Use the existing `StoryResource`: original VizForge StorySpec plus view-only cues. Controls and figure share one player per resource. Never start a second timer to animate the same fields.

A narrative step is not a telemetry sample or a model run. Cues change only view fields. Financial/scientific inputs and expensive tasks remain independent. Source examples live in `clients/wind-reference/story.ts`.

Keep palettes and narrative in the client. Reduced motion, hidden pages, restore and unmount stop autoplay. Extend with an optional scene only after a real spatial requirement is clear.
