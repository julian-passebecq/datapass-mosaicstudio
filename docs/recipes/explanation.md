# Semantic explanations

The `explanation` block wraps the original ConceptMotion loop/ordered-item contract. A client authors stable IDs, code lines, captions and bounded scalar frames. The integer frame field is view state.

Use this for transformations, invariants and algorithm explanations, not as a notebook editor. Code is displayed; it is not executed or automatically traced. Do not imply every historical ConceptMotion family is supported by the current adapter.

Reference: `clients/experience-reference/explanation.ts`. The framework uses the donor's compact viewport and theme APIs. Client authors need the contract and their frames, not all SVG source files.
