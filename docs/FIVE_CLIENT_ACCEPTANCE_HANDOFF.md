The framework work and the five real client deliveries are separate. The references in this repository prove bounded primitives with declared synthetic content. They do not certify a current Galaxy registry, real Foil'o geometry, engineering results or the latest approved portfolio copy. No client is marked complete solely because its scaffold builds.

## Boundary for client agents

Start with `docs/recipes/START.md`, choose a family, scaffold one client and edit its own files. Do not patch renderer internals to fill ordinary content. Keep source IDs, units, versions and provenance explicit. A useful minimal client is preferable to five custom engines.

The shared work now offers a narrow semantic annotation path for motion. A universal SemanticOverlay is not required by this slice. A cross-capability overlay should only be proposed with at least one concrete incompatibility and acceptance case.

## Completion evidence for each real slice

Record the client commit, approved source manifest, producer/model versions where relevant, isolated build output, browser scenarios, screenshot set, payload result and known limitations. Check keyboard access, reduced motion, narrow viewport, evidence selection, snapshot restore, external requests and unexpected capability payload. A visual field is not a substitute for source-backed computation.

Public release additionally needs a reviewed publication profile, asset/source approval, actual target-device and screen-reader checks, hosting/domain configuration and an explicit release decision. Existing CI evidence is not a complete accessibility or production-security audit.

## Integration order

Finish qualification of the shared Pro branch first. Then build the compact public route and the registry-backed Galaxy slice to expose remaining generic UI/API gaps. In parallel only after input ownership is clear, connect the approved Foil'o producer and geometry. Use the D3 lab to demonstrate bounded motion, not to accumulate speculative engine features.

This handoff is an execution contract and gap register, not a claim that those real slices have been implemented in this change.
