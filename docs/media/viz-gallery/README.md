# Viz gallery product video (VIZ-N2)

Synthetic data only. Generated by `tools/record_gallery.mjs`; do not edit by hand.

- `gallery.mp4`: 1280x720, 30 fps, H.264, about 35 s (committed because it is under 5 MB).
- `01-overview.png` … `06-lasso.png`: stills taken from the same frames.
- `metadata.json`: timeline, captions, still and video hashes, and the frame check
  (no crossfade double exposure, no single-frame flashes).

Regenerate:

```
node tools/record_gallery.mjs --ffmpeg <path-to-ffmpeg>
```
