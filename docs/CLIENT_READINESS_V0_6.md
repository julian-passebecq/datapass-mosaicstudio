# Client readiness after the foundation pass

This is an evidence-driven readiness map, not a completion percentage or a promise that one more pass covers every client.

| Client | Reusable pieces now available | Still needed for the real client |
| --- | --- | --- |
| Galaxy | Stable semantic entity/facet/projection/depth contracts, atomic view fields, ID-only links, ContextInspector, existing explorer/architecture/spatial rendering | Canonical registry mapping, meaningful relation layouts, authored camera/zoom choreography and final Fabric-inspired design |
| Foil'o engineering | Exact parameters and task outcomes, captured run comparison, result representations, static evidence/context, existing sampled replay and procedural 3D | Approved physical model/data/assets, backend/persistence only where needed, real scientific tests and client-specific engineering views |
| Compact portfolio | Lightweight content/custom React, selective capabilities, optional motion, public metadata and controlled source evidence | Final compact design/content, deployment domain, approved imagery, localization and target-device checks; 3D remains optional |
| Animated D3 lab | Existing VizForge/ConceptMotion/Motion, stable identity, finite transitions, declared cadence, shared inspector/source context | Curated examples, advanced annotation/choreography cases and usability checks driven by those examples |
| Foil'o product teardown | Existing procedural assembly, camera/explode/selection controls and evidence UI | A real ModelAsset GLTF/GLB path with approved assets, semantic part mapping, richer modes/anchors and client acceptance |

## Do not blur these boundaries

Run history is in-memory, not durable persistence or a cloud execution receipt. Provider/model names are declared metadata. Local dataset revisions are cache versions, not content hashes. Comparison requires matching declared contracts but does not establish numerical correctness.

Knowledge is approved static source reading/search/context, not ingestion/RAG/LLM. Semantic navigation does not implement a layout engine, general graph analysis or 3D camera timeline. The static publication profile does not translate/prerender the app or authenticate viewers.

No Rust rewrite, general Scenario Engine, SemanticOverlay renderer, GLTF/GLB loader, full Python notebook, DuckLake persistence, remote X-ray, or PDF/PPTX/video exporter is claimed by this pass. These are separate, testable extensions. Do not make the compact portfolio wait for every specialist feature.

## Next author boundary

Start a client in clients/<id>, generate focused context, and use the smallest appropriate capability. An ordinary client should not need to modify src/framework. Record a narrow reproducible gap when it does. Do not fork the shared scheduler or create a parallel selection store. Real datasets, assets, domain logic, scientific assumptions and approval remain client-owned.
