# Motion / reference client

Two source-owned pedagogical examples exercise the same generic motion block: a data journey and an on-demand module. All figures, timings and snippets are synthetic/authored. Neither example executes Python/SQL or measures runtime performance.

The examples demonstrate 2D and isometric SVG, deterministic seeking, source line references, context inspection and explicit script-free exports. They do not reproduce uploaded branded assets or copy an old application shell.

Run the selected build with `npm run build:client -- motion-reference`. No 3D, notebook or data-workbench capability is needed.
