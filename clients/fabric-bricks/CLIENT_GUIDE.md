# Start here

Family: spatial. This client deliberately keeps all Fabric-specific experiment code in `clients/fabric-bricks/`.

Read `SOURCE_STATUS.md` before changing domain content. Current content and geometry are synthetic/provisional. Do not relabel them as approved assets.

The interaction contract is: one stable semantic selection field across 2D and 3D, client-owned detail state, selection-driven camera focus, optional presentation-only explode, lazy 3D import, responsive layout and reduced-motion-safe behavior.

Run `npm run client:context -- fabric-bricks` for the framework reading list. Do not modify `src/framework` unless this real client reproduces a generic defect and that repair is handled separately with a targeted regression.
