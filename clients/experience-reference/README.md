# Experience reference

Synthetic acceptance client for a reusable system explorer. It is not Julian's portfolio and does not copy client claims, certifications, official icons, or a previous website shell.

One content document drives three views: procedural 3D, a React Flow relationship map, and a searchable document library. Context facets, domain filtering, explicit project navigation and view-only URL links use the same state. The optional native scroll tour is opt-in on sufficiently large screens, disabled by reduced motion; previous/next and direct selection remain available everywhere.

`atlas.ts`, `scene.ts`, `explanation.ts` and `app.ts` belong to this reference. Geometry uses generic primitives, not commercial cloud marks or final project models. Diagram content remains artifact-backed and algorithm frames are authored, not execution traces.
